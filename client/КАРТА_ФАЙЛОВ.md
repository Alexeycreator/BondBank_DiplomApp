# Карта файлов клиента BondBank

Документ описывает структуру клиентского приложения и назначение файлов, существующих на момент его создания. Пути указаны относительно папки `client`.

## Корень проекта

- `.env` — локальные переменные окружения, например адреса API. Не публикуйте значения с секретами и не добавляйте их в документацию.
- `.gitignore` — список файлов и папок, которые Git не должен отслеживать.
- `package.json` — сведения о npm-проекте, его зависимостях и командах запуска, сборки и тестирования.
- `package-lock.json` — зафиксированные версии npm-зависимостей для воспроизводимой установки.
- `README.md` — вводная документация проекта и стандартные команды Create React App.
- `tsconfig.json` — настройки компилятора TypeScript.
- `КАРТА_ФАЙЛОВ.md` — этот документ со структурой проекта и назначением файлов.
- `node_modules/` — установленные npm-пакеты. Создается командой `npm install`, вручную не редактируется и обычно не включается в Git.

## `public/`

- `public/index.html` — HTML-шаблон приложения; React подключается в элемент с идентификатором `root`.

## `src/`

- `src/App.tsx` — корневой компонент приложения: провайдер авторизации, маршрутизация, общие шапка и подвал, страницы и проверка доступности сервера.
- `src/index.tsx` — точка входа React: подключает приложение, глобальные стили и Bootstrap, монтирует React в `#root`.
- `src/index.module.css` — базовые стили документа и корневого контейнера приложения.
- `src/declaration.d.ts` — дополнительные объявления типов TypeScript для ресурсов или модулей проекта.
- `src/react-app-env.d.ts` — типовые объявления окружения Create React App.

### `src/components/`

Общие компоненты, контекст и инфраструктура, используемые страницами приложения.

- `src/components/ProtectedRoute.tsx` — ограничение доступа к защищенным страницам по авторизации и роли пользователя.

#### `src/components/context/`

- `src/components/context/AuthContext.tsx` — контекст и провайдер состояния авторизации; предоставляет сведения о текущем пользователе и операции входа/выхода.

#### `src/components/data/`

Модули запросов к серверу, демонстрационные данные и типы данных API.

- `src/components/data/api.tsx` — общая настройка Axios-клиента, базовый URL API и обработка сетевых ошибок.
- `src/components/data/bondsPageApi.tsx` — запросы данных для раздела облигаций.
- `src/components/data/mainPageApi.tsx` — запрос статистики для главной страницы.
- `src/components/data/mockData.tsx` — демонстрационные пользователи и новости для тестирования интерфейса. Содержит фиктивные учетные данные, не предназначенные для реальной авторизации.

##### `src/components/data/types/`

- `src/components/data/types/bondHistory.tsx` — типы истории и динамики облигаций.
- `src/components/data/types/bonds.tsx` — типы данных облигаций.
- `src/components/data/types/bondsInfo.tsx` — типы сводной информации об облигациях.
- `src/components/data/types/common.tsx` — общие типы, используемые несколькими моделями данных.
- `src/components/data/types/currencyRates.tsx` — типы валютных курсов.
- `src/components/data/types/index.tsx` — общий экспорт типов из этой папки.
- `src/components/data/types/mainPage.tsx` — типы данных главной страницы, включая статистические блоки.

#### `src/components/header/`

- `src/components/header/Header.tsx` — верхняя панель и навигация приложения.
- `src/components/header/Header.module.css` — стили шапки.

#### `src/components/footer/`

- `src/components/footer/Footer.tsx` — нижняя часть интерфейса приложения.
- `src/components/footer/Footer.module.css` — стили подвала.

#### `src/components/errorCard/`

- `src/components/errorCard/ErrorCard.tsx` — переиспользуемое отображение ошибки в интерфейсе.
- `src/components/errorCard/ErrorCard.module.css` — стили карточки ошибки.

#### `src/components/spinner/`

- `src/components/spinner/Spinner.tsx` — индикатор загрузки.
- `src/components/spinner/Spinner.module.css` — стили индикатора загрузки.

#### `src/components/pagination/`

- `src/components/pagination/PaginationControl.tsx` — управление переключением страниц списка.
- `src/components/pagination/PaginationControl.module.css` — стили пагинации.

#### `src/components/importExport/`

- `src/components/importExport/ImportBonds.tsx` — импорт данных об облигациях из файла.
- `src/components/importExport/ExportBonds.tsx` — экспорт данных об облигациях в файл.
- `src/components/importExport/ImportExport.module.css` — общие стили элементов импорта и экспорта.

#### `src/components/serverHealthCheck/`

- `src/components/serverHealthCheck/ServerHealthCheck.tsx` — проверка доступности серверной части и обработка состояния соединения.

#### `src/components/types/`

- `src/components/types/index.tsx` — общие типы клиентской части, не относящиеся непосредственно к типам ответов API.

### `src/components/pages/`

Страницы, подключаемые маршрутизатором в `src/App.tsx`. CSS-файлы с суффиксом `.module.css` содержат локальные стили соответствующих страниц.

#### `src/components/pages/mainPage/`

- `src/components/pages/mainPage/MainPage.tsx` — главная страница со сводной информацией.
- `src/components/pages/mainPage/MainPage.module.css` — стили главной страницы.

#### `src/components/pages/bondsPage/`

- `src/components/pages/bondsPage/BondsPage.tsx` — каталог или список облигаций и связанные с ним действия.
- `src/components/pages/bondsPage/BondsPage.module.css` — стили страницы облигаций.

#### `src/components/pages/forecastsPage/`

- `src/components/pages/forecastsPage/ForecastsPage.tsx` — страница прогнозов рынка.
- `src/components/pages/forecastsPage/ForecastsPage.module.css` — стили страницы прогнозов.

#### `src/components/pages/portfoliosPage/`

- `src/components/pages/portfoliosPage/PortfoliosPage.tsx` — страница портфелей пользователя; маршрут защищен авторизацией.
- `src/components/pages/portfoliosPage/PortfoliosPage.module.css` — стили страницы портфелей.

#### `src/components/pages/profilePage/`

- `src/components/pages/profilePage/ProfilePage.tsx` — профиль пользователя; маршрут защищен авторизацией.
- `src/components/pages/profilePage/ProfilePage.module.css` — стили профиля.

#### `src/components/pages/authPage/`

- `src/components/pages/authPage/AuthPage.tsx` — страница входа и/или регистрации.
- `src/components/pages/authPage/AuthPage.module.css` — стили страницы авторизации.

#### `src/components/pages/newsPage/`

- `src/components/pages/newsPage/NewsPage.tsx` — список новостей.
- `src/components/pages/newsPage/NewsPage.module.css` — стили новостной страницы.

#### `src/components/pages/aboutUsPage/`

- `src/components/pages/aboutUsPage/AboutUsPage.tsx` — страница с информацией о проекте или сервисе.
- `src/components/pages/aboutUsPage/AboutUsPage.module.css` — стили страницы «О нас».

#### `src/components/pages/adminPage/`

- `src/components/pages/adminPage/AdminPage.tsx` — административная панель; маршрут доступен пользователям с правами администратора.
- `src/components/pages/adminPage/AdminPage.module.css` — стили административной панели.

#### `src/components/pages/errorPages/`

- `src/components/pages/errorPages/BadRequestPage.tsx` — страница ошибки запроса HTTP 400.
- `src/components/pages/errorPages/ServerErrorPage.tsx` — страница серверной ошибки HTTP 500.
- `src/components/pages/errorPages/NotFoundPage.tsx` — страница для неизвестного маршрута (404).
- `src/components/pages/errorPages/ErrorPages.module.css` — общие стили страниц ошибок.

### `src/service/`

- `src/service/fileService.tsx` — вспомогательные операции с файлами, используемые клиентом.

## Полезные команды

- `npm install` — установка зависимостей.
- `npm start` — запуск приложения в режиме разработки.
- `npm test` — запуск тестов.
- `npm run build` — сборка приложения для публикации.

> Карта отражает файлы клиентской папки `client`. Серверная часть, содержимое `node_modules/` и генерируемые файлы сборки в нее не входят.
