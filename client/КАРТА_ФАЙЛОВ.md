# Карта файлов клиента BondBank

Структура указана относительно папки `client`. Исходный код приложения организован по слоям Feature-Sliced Design (FSD); страницы сохраняют собственные UI-компоненты, а повторно используемые и предметные модули размещены в соответствующих слоях.

## Инструменты и точка входа

- `package.json` — зависимости и команды Vite (`npm run dev`, `npm run build`); отдельного тестового скрипта пока нет.
- `vite.config.ts` — конфигурация Vite и dev-сервера.
- `tsconfig.json` — строгие настройки TypeScript.
- `index.html` — HTML-шаблон Vite.
- `src/index.tsx` — подключение глобальных стилей, инициализация Keycloak и монтирование React.
- `src/index.module.css` — глобальные стили приложения.
- `src/keycloak.ts` — конфигурация клиента Keycloak.

## FSD-слои

### `src/app/`

- `App.tsx` — общие провайдеры, оболочка приложения и подключение маршрутизатора.
- `router.tsx` — таблица маршрутов.
- `route-guards.tsx` — проверки авторизации и роли для защищённых маршрутов.

### `src/pages/`

Страницы маршрутов с локальными CSS Modules:

- `mainPage/`, `bondsPage/`, `forecastsPage/`, `portfolios/ui/`;
- `profilePage/`, `adminPage/`, `newsPage/`, `aboutUsPage/`;
- `errorPages/` — 400, 500 и 404;
- `authPage/` — отдельная страница авторизации, сейчас не подключена в маршрутизатор.
- `mainPage/api/` и `mainPage/model/` — запрос и DTO главной страницы.
- `portfolios/ui/` — страница портфелей и её локальные компоненты списка, выбора даты и деталей.
- `aboutUsPage/ui/`, `bondsPage/`, `forecastsPage/ui/`, `mainPage/ui/` и `newsPage/ui/` — компоненты, используемые только соответствующими страницами.
- `mainPage/ui/MainShowcase.tsx` и `MainContentSections.tsx` — карусель-демо и независимые секции главной; содержимое и демонстрационные значения находятся в `mainPage/model/content.ts`.
- `forecastsPage/model/` — тип прогноза и демонстрационный набор; `ui/ForecastChart.tsx` отвечает за график выбранного прогноза.
- `adminPage/model/mock-data.ts` и `portfolios/model/mock-data.ts` — демонстрационные источники для пока не подключённых API. Они остаются пустыми, как и прежде; таймерная имитация загрузки сохранена.
- `adminPage/ui/AdminConfirmationModals.tsx` — подтверждение отмены изменений и удаления пользователя/новости.

### `src/entities/`

- `bond/model/` и `bond/api/` — доменные типы, DTO backend, преобразование данных облигаций и запрос списка.
- `bond/ui/BondDetailsCard.tsx` — представление деталей облигации.
- `news/model/` — типы и демонстрационные новости, включая расширенный набор; карточка новости отвечает только за отображение.
- `portfolio/model/` — типы портфелей, состава портфеля, истории и единые параметры типов портфеля.
- `portfolio/ui/PortfolioCard.tsx` — карточка портфеля.
- `user/model/` и `user/api/` — модели пользователя, ролей и профиля, запрос данных профиля.

### `src/features/`

- `bond/import-export/ui/` — импорт и экспорт облигаций в CSV.
- `portfolio/create/ui/` — модальное окно создания портфеля.
- `portfolio/view-bond/ui/` — карточка деталей облигации из портфеля.

### `src/widgets/`

- `portfolio-charts/ui/` — набор графиков портфеля и его локальные стили.
- `site-header/ui/`, `site-footer/ui/`, `breadcrumbs/ui/` — общая оболочка и навигация.
- `server-health-check/ui/` — проверка доступности backend.

### `src/shared/`

- `api/client.ts` — общий Axios-клиент и нормализация сетевых ошибок.
- `lib/routing/useUrlQuery.ts` — чтение и точечное обновление query-параметров с сохранением остальных параметров URL. Используется страницами облигаций и портфелей; не каждая страница приложения хранит состояние в query string.
- `auth/AuthContext.tsx` — состояние авторизации на основе Keycloak.
- `notifications/ToastContext.tsx` — общий механизм уведомлений.
- `ui/` — таблица, фильтры, графики, пагинация, индикатор загрузки, карточка ошибки и бейджи.

## Другие модули

- `src/service/fileService.tsx` — не подключённая к UI утилита CSV-импорта/экспорта облигаций; при следующем изменении стоит подключить её или удалить как неиспользуемую.
- `public/` — публичные файлы, включая `silent-check-sso.html` для Keycloak.

Для проверок используйте `npm run build` и `npx tsc --noEmit`. Проект пока не содержит отдельного тестового набора.

FSD не требует универсального лимита строк на компонент: крупные страницы следует разделять по самостоятельным зонам ответственности. В частности, страница портфелей уже делегирует список, выбор периода и детали локальным компонентам; другие крупные страницы остаются кандидатами для таких же точечных извлечений.
