# Карта файлов клиента BondBank

Карта описывает текущую структуру приложения относительно папки `client`. Код организован по слоям Feature-Sliced Design: маршруты и композиция находятся в `app`, страницы — в `pages`, предметные модели и API — в `entities`, пользовательские действия — в `features`, общие части интерфейса — в `widgets` и `shared`.

## Корень проекта

- `package.json` — зависимости и команды `npm run dev`, `npm run build`, `npm run preview`. Отдельного тестового скрипта нет.
- `vite.config.ts` — конфигурация Vite.
- `tsconfig.json` — настройки TypeScript со строгой проверкой.
- `index.html` — HTML-шаблон приложения.
- `README.md` — инструкции по запуску и настройке окружения.
- `.env` — локальные адреса API; не добавляйте сюда секреты.
- `public/` — публичные файлы, включая `silent-check-sso.html` для Keycloak.
- `.github/skills/` — локальные вспомогательные скилы и их данные; это не runtime-код приложения.

## Точка входа и приложение

- `src/index.tsx` — подключает глобальные CSS и Bootstrap, инициализирует Keycloak и монтирует React.
- `src/index.module.css` — глобальные дизайн-токены, базовые правила, состояния фокуса и темы.
- `src/keycloak.ts` — создание и настройка клиента Keycloak.
- `src/app/App.tsx` — провайдеры темы, авторизации и уведомлений, общая оболочка, шапка, хлебные крошки и подвал.
- `src/app/router.tsx` — таблица маршрутов приложения.
- `src/app/route-guards.tsx` — защита маршрутов авторизацией и ролью администратора.

## Страницы — `src/pages/`

- `mainPage/` — главная страница, загрузка статистики из API, секции возможностей и демонстрационная карусель.
  - `api/mainPageApi.ts` — запрос блока статистики.
  - `model/content.ts` — текстовые секции и иллюстративные данные макетов карусели; они не являются данными API.
  - `model/types.ts` — тип статистического блока.
  - `ui/` — карусель, карточка функции и секции главной страницы.
  - `MainPage.module.css` — локальное оформление главной страницы.
- `bondsPage/` — каталог облигаций, фильтры, таблица, график истории, подробности и экспорт/импорт.
- `forecastsPage/` — страница прогнозов, загрузка данных и локальные компоненты карточки и графика.
  - `api/forecastsApi.ts`, `model/api-types.ts`, `model/useForecasts.ts`, `model/forecast-dates.ts` — запросы, DTO и состояние прогнозов.
- `portfolios/ui/` — страница портфелей и компоненты списка, управления датами и деталей.
- `profilePage/` — профиль и персональные данные пользователя.
- `adminPage/` — панель администратора.
  - `ui/AdminUsersPanel.tsx` и `ui/AdminNewsPanel.tsx` — таблица пользователей и управление серверными новостями.
  - `ui/AdminConfirmationModals.tsx` — общие диалоги подтверждения.
- `newsPage/` — новости из серверного API, фильтрация по категориям и состояния загрузки/ошибки/пустого списка.
  - `ui/NewsCard.tsx` — карточка публикации.
- `aboutUsPage/` — страница о проекте и её карточки миссии, команды и ценностей.
- `errorPages/` — страницы ошибок 400, 404 и 500.
- `authPage/` — страница авторизации; сейчас отдельный маршрут для неё не задан.

## Предметные модули — `src/entities/`

- `bond/`
  - `api/bondsApi.ts` — каталог, фильтры, данные по ISIN и прогнозы облигаций.
  - `api/bondHistoriesApi.ts` — история облигаций, фильтры и типы.
  - `model/` — DTO, типы облигаций и истории, типы бирж, сведения для страницы и преобразование DTO в модель представления (`bond-mappers.ts`).
  - `ui/BondDetailsCard.tsx` — представление сведений об облигации.
- `currency/`
  - `api/currencyRatesApi.ts` — курсы, фильтр по дате/валюте и список валют.
  - `model/types.ts` — DTO курса валют.
- `news/`
  - `api/newsApi.ts` — получение, фильтрация, сохранение и удаление новостей.
  - `model/types.ts` — DTO ответа и запроса новости (`id`, `category`, `date`, `title`, `image`, `body`); моковых новостей нет.
- `portfolio/`
  - `api/portfoliosApi.ts` — чтение, сохранение, удаление портфеля и чтение истории.
  - `model/` — DTO API, типы и параметры видов портфеля, загрузка пользовательских портфелей.
  - `ui/PortfolioCard.tsx` — карточка портфеля.
- `user/`
  - `api/usersApi.ts` — профиль, административный список, поиск и heartbeat пользователя.
  - `api/securityDataApi.ts` — чтение/сохранение/удаление паспортных данных и СНИЛС.
  - `model/` — DTO пользователя, администратора, паспорта и СНИЛС; `useAdminUsers.ts` загружает список для панели управления.

## Пользовательские действия — `src/features/`

- `bond/import-export/` — импорт CSV на сервер с выбором биржи и экспорт таблицы облигаций в CSV.
- `portfolio/create/` — форма создания портфеля.
- `portfolio/view-bond/` — модальное окно деталей облигации в портфеле.

## Компоновочные блоки — `src/widgets/`

- `site-header/` — адаптивная шапка, навигация, аккаунт и переключатель темы.
- `site-footer/` — общий подвал.
- `breadcrumbs/` — хлебные крошки.
- `portfolio-charts/` — графики портфеля.
- `server-health-check/` — проверка доступности API.

## Общая инфраструктура и UI — `src/shared/`

- `api/client.ts` — Axios-клиент, добавление токена Keycloak и нормализация API-ошибок.
- `api/healthApi.ts` — DTO и запрос проверки состояния API.
- `auth/AuthContext.tsx` — состояние авторизации и роли на основе Keycloak.
- `theme/ThemeContext.tsx` — управление светлой и тёмной темой.
- `notifications/ToastContext.tsx` — общие уведомления.
- `lib/routing/useUrlQuery.ts` — чтение и обновление query-параметров URL.
- `ui/` — таблица, графики, карточки, фильтры, пагинация, спиннер, статус и индикатор ёмкости.

## Сервисные и типовые файлы

- `src/service/filesApi.ts` — клиентские запросы импорта и экспорта файлов.
- `src/service/fileService.tsx` — вспомогательная реализация работы с файлами.
- `src/declaration.d.ts`, `src/vite-env.d.ts` — декларации модулей и переменных окружения.

## Проверки

- `npx tsc --noEmit` — проверка типов.
- `npm run build` — production-сборка.
- В `package.json` нет отдельной команды запуска тестов.
