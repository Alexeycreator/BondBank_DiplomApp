# BondBank - Система мониторинга и анализа облигаций

## 📊 О проекте

BondBank — это полнофункциональная платформа для сбора, анализа и мониторинга данных об облигациях с ведущих мировых бирж. Система автоматизирует процесс получения данных через парсеры, предоставляет API для работы с данными и интерактивный веб-интерфейс для пользователей.

### Основные возможности

- 🔄 **Автоматический сбор данных** — фоновые процессы парсинга данных с 4-х бирж
- 📈 **Хранение исторических данных** — отслеживание изменений цен и курсов валют
- 📊 **Визуализация данных** — интерактивные графики и таблицы на React + TypeScript
- 🔍 **API для работы с бондами** — получение данных по ISIN, типу и др.
- 🏦 **Управление портфелями** — создание и отслеживание пользовательских портфелей
- 💱 **Актуальные курсы валют** — ежедневное обновление курсов

### Настройка базы данных

Для корректной работы приложения необходима база данных **PostgreSQL 16+**.

1. **Установите PostgreSQL**  
   Скачайте и установите PostgreSQL с [официального сайта](https://www.postgresql.org/download/).

2. **Примените миграции**  
   Перед запуском сервера выполните команды для создания базы данных и применения миграций:

   ```bash
   # Установка глобального инструмента EF Core (если ещё не установлен)
   dotnet tool install --global dotnet-ef

   # Применение миграций к базе данных
   dotnet ef database update
   
**_Примечание: Команды выполняются в корневой папке проекта или в папке BondBank_WebApi_**

## ▶️ Запуск приложения
Команды для перехода между проектами:
```
    cd BondBank_WebApi
    cd BondBank_Frontend
    cd TelegramBot
    cd Parsers/WeinerBoerseParser
    ...
```

```

```

```
    npm run build
```
**_Примечание: все команды, начинающиеся на ключевое слово ```dotnet``` являются командами для .NET приложений, команды ```npm``` для клиентского приложения._** 

## 🧪 Тестирование API

**_Swagger UI_**
После запуска Web API Swagger доступен по [адресу](https://localhost:7240/swagger/index.html)
Основные эндпоинты:
Метод	URL	Назначение
```
GET	/api/Bonds/get-all-bonds Получить все облигации
GET	/api/Bonds/get-bond-by-isin?isin={isin}	Получить облигацию по ISIN
GET	/api/Bonds/get-bonds-by-type?typeBond={type}	Получить облигации по типу
POST	/api/ExportImportFiles/import-bonds	Импорт файла с данными
GET	/api/BondHistory/history/{isin}	Получить историю облигации
```
## 🧩 Ключевые компоненты
1. Фоновые процессы (Background Services)

| Сервис | Назначение |
|--------|------------|
| **CurrencyRatesBackgroundService** | Получение и обновление курсов валют (каждые 30 минут, с 8:00 до 17:00) |
| **ParserDataBackgroundService** | Обработка данных от парсеров бондов |
| **SavedBondHistoriesBackgroundService** | Сохранение истории бондов |

2. Общая библиотека (Shared)

| Компонент | Назначение |
|-----------|------------|
| **ConnectionMonitor** | Мониторинг подключений к внешним ресурсам |
| **BotService** | Отправка уведомлений в Telegram |
| **CsvService** | Работа с CSV файлами |
| **ConfigLoader** | Загрузка конфигурации |
